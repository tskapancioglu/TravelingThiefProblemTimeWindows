# TTPTW Generated Instances

**Number of instances**: 32

**Number of width parameters**: 4

 - $l \in$ {-2, -4, 4, 2}, here ordered by descending time window width.

**Number of tours considered**: 2

- **Type A**: Optimal TSP tour

- **Type B**: Random tour <br><br>


The TTPTW instance named "sym_similar_17_1_50_TW_A_2" was created using the TTP instance "sym_similar_17_1_50" as a baseline, and its time windows were generated using the optimal TSP tour (instance **type A**) and a width parameter $l = 2$. <br><br>



The generated instances were created using the following TTP instances as baseline, introduced in [https://10.1016/j.ejor.2026.08.002](https://doi.org/10.1016/j.ejor.2026.08.002) and available at [https://github.com/tskapancioglu/TravelingThiefProblem](https://github.com/tskapancioglu/TravelingThiefProblem) :

- sym_similar_24_3_50.ttp

- sym_similar_24_1_50.ttp

- sym_similar_17_3_50.ttp

- sym_similar_17_1_50.ttp <br><br>



**Note:** the <ins>**time windows are presented at the end of the file**</ins> (since the file contains explicit traveling cost matrices), unlike in the benchmark instances where they are presented next to the node coordinates.
